# SA2_Programa-o_de_Aplicativos_SENAI
Code developed for Learning Situation 2 of the Application Programming subject.

<h5> The List file executes with the following parameters: <h5>
1. Given the list L = [5, 7, 2, 9, 4, 1, 3], write a program that prints the following information:
a) size of the list;

b) largest value in the list;

c) smallest value in the list;

d) sum of all elements in the list;

e) list in ascending order;

f) list in descending order.

<h5> The Average_of_4 file executes with the following parameters:<h5>
2. Write a program that reads 4 values, calculates the average and prints positive or negative (to be positive the average must be above 1).

<h5> The Media_of_20 file executes with the following parameters:<h5>
3. Write a program that reads 20 integer values ​​and reports their average, the largest, and the smallest value.

<h5> The Line file executes with the following parameters:<h5>
4. Create a function to draw a line, using the '_' (underscore) character. The line size should be defined in the function call.

<h5> The Print file executes with the following parameters:<h5>
5. Create a function that receives a list as a parameter, with values ​​of any type. The function should print all the elements of the list, enumerating them.

<h5> The Converter file executes with the following parameters:<h5>
6. Create a program that converts hours into seconds, according to the value that the user enters when prompted.

<h5> The list file executes with the following parameters:<h5>
7. Change the following code to the fewest possible lines while maintaining the same result:
print("   *");
print("  *  *");
print(" *    *");
print("*      *");
print("***   ***");
print("  *   *");
print("  *   *");
